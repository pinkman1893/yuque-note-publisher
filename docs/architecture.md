# 设计与取舍

## 两层，而不是一个全自动同步程序

Agent 层负责语义判断与发布授权，Python 层负责可重复的文件和 HTTP 操作。自动分类需要宿主 Agent 的模型能力，本项目不额外持有模型 API Key。没有定时任务、后台服务、全局知识库扫描或自动推送程序。

```text
用户选择 → Agent 审查与决策 → scripts/ 可验证操作 → Agent 校验并 Git 发布
                                  ↓
                           私有缓存 / 预算 / 断点
```

## 自包含 skill，单一脚本来源

```text
skills/yuque-note-publisher/
├── SKILL.md
├── references/workflow.md
└── scripts/
    ├── yuque_note.py
    ├── publish_checkpoint.py
    ├── update_history.py
    ├── update_homepage.py
    └── runtime.py
```

Python 包的源码直接映射到这个 scripts 目录；`pyproject.toml` 暴露四个命令。没有第二套脚本副本需要同步。复制 skill 即可独立运行；安装包得到相同实现。pip 的数据文件包含 skill 说明，但自动安装到某个 Agent 目录由使用者决定。

## 状态与配额

账本按上海日期记录本工具的 API 尝试数，不代表账户总量。尝试前预留额度，失败不回退，避免乐观低估。排他锁保护计数读改写，冲突时直接停止。进程异常退出遗留锁时由操作者确认进程停止后处理，不冒险自动解锁。

checkpoint 保存有序队列和当前轮，不只保存三条。advance 必须精确匹配当前轮；ready-to-clear 才正常清除。它不支持多个 Agent 同时发布，整个工作流要求串行。

正文缓存以 namespace 和文档选择绑定，防止路径复用串篇。图片单独记录缓存，不重复扣正文请求。私有状态不能复制到公开项目。

## 发布约束

创建日期是不变元数据；最近整理的排序与展示日期分别处理。学习更新只描述内容演进。目录和公式修复不是学习成果，助手与作者的沟通过程也不应出现在公开记录中。

课程和刷题可能共享算法概念，但内容用途不同；目录选择必须读取语境。分类既不是按关键词硬映射，也不是按语雀目录复制。

## 当前限制

- 运行时仅标准库，图片处理是 URL 本地化，不负责图像编辑或完整富文本解析。
- 图片通过 Content-Type/非空检查，实际解码和截图遮挡还需 Agent 的视觉检查。
- 不自动解决语雀权限、会员配额或不可访问附件。
- 不支持多任务并发发布；账本锁仅保证计数安全。
- 固定以 Asia/Shanghai 计算笔记日期和账本日界，是当前面向中文学习记录的明确选择。
- Git 身份、凭据和目的仓库权限由使用者配置；工具不创建凭据，不写 Git 全局设置。
